## 📚 Contenido de la materia

### 🧱 HTML
**HyperText Markup Language.** Es el lenguaje de marcado que define la **estructura** de una página web. Mediante etiquetas (`<h1>`, `<p>`, `<div>`, `<form>`…) se organizan títulos, párrafos, imágenes, enlaces y formularios.

### 🎨 CSS
**Cascading Style Sheets.** Es el lenguaje que define la **presentación visual** del HTML: colores, tipografías, márgenes, posiciones y diseño adaptable (*responsive*) con herramientas como Flexbox y Grid.

### ⚡ JavaScript
Lenguaje de programación que aporta **interactividad y lógica** a las páginas web. Permite manipular el DOM, responder a eventos del usuario, consumir APIs y, con Node.js, ejecutarse también en el servidor.

### 🔷 TypeScript
Superconjunto de JavaScript desarrollado por Microsoft que añade **tipado estático**. Ayuda a detectar errores antes de ejecutar el código, mejora el autocompletado y facilita el mantenimiento de proyectos grandes. Se compila a JavaScript.

### 🐈 NestJS
Framework de **backend** para Node.js construido con TypeScript. Usa una arquitectura modular basada en **módulos, controladores y servicios**, e incorpora inyección de dependencias, lo que permite crear APIs REST escalables y ordenadas.

### ⚛️ ReactJS
Biblioteca de JavaScript creada por Meta para construir **interfaces de usuario** en el frontend. Se basa en **componentes reutilizables**, el manejo de estado (`useState`, `useEffect`) y un DOM virtual que actualiza la vista de forma eficiente.
